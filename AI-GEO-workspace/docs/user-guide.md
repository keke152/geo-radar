# 网页与API操作手册

v1.2执行规则以[并行、连续会话与自动采集说明](execution-v120.md)为准：不同平台可并行；创建时可选择连续对话；正常采集自动校验入库，异常才需要人工处理。以下早期版本说明保留作连接步骤参考。

## 网页接入

最新版有四步连接向导，详见[连接指引](connection-fix.md)。网页模式不需要API Key。

v1.0.2增加“定位输入框”、取消标定与弹窗内保存回执，详见[显示与保存操作说明](input-and-save-fix.md)。点选结果先保留在当前表单，只有点保存才写入正式配置。

v1.0.3已完成本机豆包实际发送与回答获取。窗口必须由当前工作台服务接管；窗口被其他进程管理时，第二步会显示原因，不再笼统要求重装Edge。弹窗关闭按钮固定在顶部，正文单独滚动。

v1.0.4将窗口、输入框、登录确认和发送方式分开显示。第三步可“自动识别控件（不发送）”，再检查并保存。空输入时禁用的发送按钮会显示已找到、待输入，不再混同未识别；SVG会归一到外层控件，误选输入框不能作为发送按钮通过。详见[连接状态说明](connection-states-v104.md)。

每个平台有独立的Edge用户资料目录。本工具不能使用或读取你普通浏览器里已有的登录信息。点“打开登录”后，在新窗口本人登录，并回到问答页面。遇到验证码、短信或安全确认时请本人完成；工具不会绕过验证。

开始标定前暂停队列，等待当前任务结束。点“连接向导”：

1. **输入框**：点“点选输入框”，到专用浏览器点击实际可输入文字的区域。
2. **发送按钮**：点“点选发送按钮”，到浏览器点击发送图标。此次点击被标定器拦截，不会发送。找不到按钮时，可在“发送方式”明确选择平台支持的快捷键。
3. **新对话**：点选能创建新会话的按钮。独立对话模式需要此项；连续对话直接复用当前聊天，并排除在独立可见度样本之外。
4. **回答区域（可选）**：先取消标定，由本人发一个简单问题，待回答出现后，点选AI回答的文本容器。高级设置中应使用匹配每条回答的通用选择器，避免只指向历史某条回答。
5. 检查输入框，查看高级选择器。勾选已校准并允许发送后保存。保存前会验证可编辑输入框、配置的发送按钮和新对话按钮是否仍存在。失败会在保存按钮上方说明原因；成功会保留时间与规则值回执。未完成时取消勾选即可先保存草稿。

点选依据data-testid、aria-label、placeholder、title、id或DOM路径生成选择器。平台更新界面后可能需要重新标定。页面中嵌套的iframe/封闭Shadow DOM及某些编辑器不在当前通用实现保证范围内。只有找得到输入框和可用发送按钮时才尝试发送。

默认入口为豆包、DeepSeek、Kimi、千问、腾讯元宝、知乎直答。知乎通道只用于直答问答，不发布知乎文章、回答或评论。

### 搜索与会话污染

本人选择平台的联网搜索模式，并确认新会话仍保留这个选项。本工具不自动猜测“联网”开关，也不能清除平台账号的长期记忆或推荐个性化。搜索检查只保证本工具不额外注入企业资料；品牌词本身仍带提示，单独标记。

### 回答截取

发送后按配置的回答选择器轮询最多90秒，文本稳定后保存；稳定不保证模型绝对生成完毕，可能出现中途停顿。没有配置回答区域时只保存发送状态与截图。请核对完整回答后录入，不把自动截取当作天然准确证据。

豆包会按原始问题匹配其后对应的AI回复。已发送的豆包任务可在详情点“重新获取回答（不重发）”：服务打开保存的原对话，核对原问题再取回答，取不到不会改用后续问题的回答。提取后仍需核对，未发送的任务不能用此操作伪造成功。

## 每日使用

“每日任务”每行一个关键词，最多5个。选择平台及模式，预览实际内容后创建任务。每批请求有唯一编号，浏览器重复请求不会重复建任务。任务按创建顺序执行，实际发送尝试后默认间隔45秒；未连接或缺配置不占用这个间隔。默认每日30条，最多设置60条/日。

v1.0.5创建后会先检查连接和必要配置，没准备好的直接显示待连接/配置；近期任务上方显示队列说明，待执行行显示排队位置与队首间隔。详见[排队状态说明](queue-status-v105.md)。

未登录、没有校准或缺Key的任务进入“待配置”，不会自动打开一批登录窗口或假装成功。配置好后在记录详情里重新排队。只允许重试未发送的待配置任务；超时、不确定、已发送及中断任务不会自动重发。

“暂停队列”阻止下一个任务和计划触发，不撤回已经发出的请求，也不立刻中止正在等回答的任务。

## 每日计划

选1–5个已保存关键词、平台、时间和模式。默认不启用，勾选启用后才运行。时间为北京时间，电脑和服务必须开着；网页窗口也要保持登录可用。每天最多触发一次，当天晚启动会补一次，不追补历史日期。未登录的计划任务进入待配置。

如果当日总量已达到限制，计划不会偷偷扩大额度；在工作台查看计划触发信息与任务记录，必要时次日调整。不要启多个服务实例共享同一浏览器目录。

## 公司资料

TXT/Markdown要求UTF-8，最大2MB；PPTX最大400MB、200页，每页文字最多20000字。不会提取图片里的文字，不跟随课件外部链接。原上传文件不保存在项目中，提取条目初始全部待核验。

允许对外的资料会进入“资料研读”和官网内容草稿。每次创建任务时固定提示词快照，之后改资料不会改变已排队或历史任务。最多合计18000字，避免无边界发送整份资料。

密钥、价格底表、未授权背书和客户个人资料不要放进公开资料卡。分享项目请使用排除了运行目录的压缩包，不要打包浏览器登录信息。

## API

`.env`只在服务启动时加载；修改后重启。没有默认模型ID，需从对应平台控制台填写。API通常需要自己的调用额度，本项目不会借用网页会员额度。元宝和知乎直答当前只有网页，不把混元、DeepSeek等其他API说成它们的消费端结果。

## 网站内容

导出的是审核草稿，既不登录官网后台，也不自动提交搜索收录。备案期间整理事实和核验材料；网站可公开访问后由维护人员确认robots、sitemap、真实页面、结构化数据及站点验证配置，再观察实际搜索回答。

## 数据和故障

- `runtime/workspace.sqlite3`：资料、关键词、计划、任务及回答。
- `runtime/browser-profiles/`：专用浏览器登录数据，应作为敏感文件保护。
- `runtime/screenshots/`：本地证据截图。
- `.env`：用户自己的API密钥，不纳入导出。

服务重启时执行中的任务改为“执行中断”，不会自动再次发送。网络异常可能意味着平台已收到请求，因此需要先核对会话/账单。关闭服务后定时功能停止。
