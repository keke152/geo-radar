# 模板导出与记录回收站（v1.8.0）

## Excel 导出

在“记录”页选择关键词、状态、平台、网页/API和模式，再点击“导出 Excel”。导出全部符合筛选的记录，不限于当前分页。CSV仍可单独下载。

主表保留用户提供的17列及顺序：日期、平台、是否联网、问题编号、完整问题、是否新对话、有没有提到我、有没有推荐我、排第几、来源里有没有我的网页、应用了哪些其他来源、说错了什么、提到了哪些竞品、AI推荐语原话、原始回答保存位置、本轮变动、备注。

| 字段 | 填写规则 |
| --- | --- |
| 日期 | 发送时间；未发送时使用创建时间。转换为北京时间，使用可排序的Excel日期值。 |
| 问题编号、完整问题 | 任务ID及创建时固定的完整提示词，不以当前资料替换历史提示词。 |
| 是否联网 | 没有独立联网核实证据时填“未核实”，不把来源链接或搜索开关直接算作已联网。 |
| 是否新对话 | 从任务保存的fresh/continue会话方式读取；旧记录缺失时填“未记录”。 |
| 有没有提到我 | 已核对回答中的品牌和企业名称命中。未核对时填“待核对”，未取得回答时明确标注。 |
| 有没有推荐我、排第几 | 不从名称提及推断推荐或排名，默认“未判定”或留空。 |
| 来源里有没有我的网页 | 只检查实际采集的来源URL域名。正文里的官网地址不等同于被引用。未采集到来源时明确标注。 |
| 应用了哪些其他来源 | 采集来源URL中排除官网域名后的部分，不编造URL。 |
| 原始回答保存位置 | 工作簿“原始回答”页的内部链接，可点击定位。 |
| 错误、竞品、推荐原话、本轮变动 | 没有已确认标注时留空，可在Excel内补充，不会自动回写工作台。 |

“原始回答”页保留完整提示词、原始回答、来源和记录ID。长文本分行保存，拼接后与原文一致；不会因为Excel单元格长度限制丢弃尾部。主表过长的问题或来源会提示去原始页查看。输入与正文写为文本，不会作为Excel公式执行。

项目自带空白模板由Artifact Tool生成，服务用Python标准库填充OpenXML，不需要安装Excel、Node或额外的表格库。原用户模板文件不被修改，本机实际回答不放入项目分发包。

## 删除与恢复

- 单条：打开记录详情，点击“删除记录”，预览数量后确认。
- 批量：记录页“清理历史”沿用当前筛选，可增加“创建日期截止至（含当天）”。日期按北京时间解释。
- 先预览再确认，只处理该次预览中的ID；之后新增的记录不会被顺带删除。预览10分钟后过期。修改截止日期后旧的在途响应不能重新启用确认，关闭弹窗后旧响应也不会干扰新弹窗。
- 排队中和执行中的任务跳过；预览后状态变为排队或执行中时，整批拒绝并要求重新预览。
- 列表、统计、连续会话历史和导出排除回收站记录；原回答、发送时间和截图保留，可在“回收站”逐条恢复。
- 已移入回收站的任务不能重试或调度。并发归档、状态变化与重试相互校验，不能通过另一个操作重新执行已归档任务。
- 恢复不会重新提问。已删除的待配置任务不能继续，正常记录恢复为原有状态，不会自动启动。旧异常记录若遗留排队/运行状态，恢复后转为待配置，先检查原会话，再由本人决定是否手动继续。
- 删除不退回当天创建额度，不撤回平台已收到的内容。回收站保留底层数据，不用于释放磁盘空间。

## 验证

记录管理19项测试通过，包含筛选导出、回收站排除与恢复、并发归档和重试保护、旧异常记录恢复后等待人工确认，以及修改条件或关闭弹窗后前端旧预览响应隔离。这些测试属于当前版本167项单元／HTTP测试的一部分。

接口测试使用临时数据库，浏览器删除操作链使用隔离的模拟记录。自动化验证不对真实记录执行删除，也不通过恢复或重试向平台重新提问。当前列表和回收站状态以本机数据为准。

## 配色与顶部

当前 v1.9.0 首页采用动态星空与地球夜景，记录页及其他内部页面统一使用深海蓝背景、分层蓝色面板、浅色正文和冰蓝强调色。保留菜单按钮、服务状态、队列开关与帮助；筛选、导出、预览、删除和恢复的操作方式保持不变。地球及轨道是视觉演示，平台状态来自本机。首页操作与发送边界见 [v1.9.0 地球场景说明](earth-scene-v190.md)。


## 人工核对回答

没有保存回答的记录不能用空内容完成核对。先使用“不重发”的自动采集入口，或从原平台会话粘贴完整回答；有有效文本后才可人工保存。空值或纯空白会被前后端同时拦截，原有回答与核对状态保持不变。详见[v1.9.3修复说明](answer-review-v193.md)。
