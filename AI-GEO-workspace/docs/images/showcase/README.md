# 展示素材说明

`cover.svg` 与 `cover.png` 是产品定位与工作流程示意图，不是运行界面截图，也不表示平台之间存在数据连接或排名关系。

其余五张 PNG 来自真实页面、样式、前端脚本及 FastAPI 接口的隔离渲染；仅在截图夹具中增加顶部「演示数据」标识。没有修改应用界面源码来构造截图。

| 图片 | 场景 |
| --- | --- |
| `home.png` | 地球产品首页与六个平台的本机连接入口；所有平台均未连接账号 |
| `workspace.png` | 任务分组与待配置、待核对、中断状态；实际后台健康运行且队列暂停 |
| `planner.png` | 本地模板生成的豆包、DeepSeek 独立问题方案；未确认创建任务 |
| `insights.png` | 核心指标与六平台明细；统计对象是明确标注的名称匹配占位文本 |
| `records.png` | 历史记录、平台及状态筛选、分页和导出入口 |

截图中的企业、品牌、任务与统计值均为合成演示数据。42 条已完成样本只包含标明「非平台回答」的名称匹配占位文本，另有 6 条状态演示记录；这些数字不能用来评价任何 AI 平台的实际表现。地球影像与卫星轨道也是本地视觉演示。

## 复现

安装项目依赖及 Microsoft Edge 后，在项目根目录执行：

```powershell
.\.venv\Scripts\python tests\showcase_capture.py
```

脚本覆盖五张截图及 `capture-report.json`，保留封面。默认视口为 1440×950；规划图使用 1440×1160，以完整展示问题卡片与确认区。统计图通过正常滚动聚焦指标与六平台明细。

## 隔离与发送保护

- `JUNHE_HOME` 指向新建临时目录；禁用 `.env` 加载，不使用用户的数据库、Cookies、浏览器配置或 API Key。
- Edge 使用全新无头浏览器上下文。全部页面 HTTP 被 Playwright 拦截，仅转交同进程的 FastAPI TestClient，不启动监听端口；外部域名请求一律阻断。
- 在 TestClient 的同一事件循环中实际启动后台及计划执行器，先设置 `paused=True`、关闭关键词计划、清空执行计划；使用真实健康接口断言两个执行器均存活且队列为 `paused`，不伪造队列响应。
- `BrowserBridge.send` 和 `engine.api_send` 均被替换为一旦调用即失败的保护桩，并断言调用次数为 0。HTTP 写操作只允许本地方案及提示词预览。
- 捕获结束断言没有新建批次、没有外部请求、没有页面脚本错误，再正常停止后台、关闭浏览器并清理临时数据。详细结果保存在 `capture-report.json`。
