# 历史记录：v1.6.0 客户端结构与交互

> 本文保留 v1.6.0 当时的界面、首页示例入口及验证记录，不代表当前配色和首页操作。当前版本为 v1.9.0，首页采用动态星空与地球夜景，内部工作台采用深海蓝、浅色正文和冰蓝强调色。首页已删除示例和辅助说明，按钮为“选择平台并检查”。请参阅 [当前版本介绍](../README.md)、[v1.9.0 地球场景说明](earth-scene-v190.md)及[记录管理说明](records-export-and-trash.md)。以下正文属于历史记录。

客户端工作区与产品首页采用统一雾白底色、白色内容面板和蓝紫强调色。科技感来自轻量交互、清晰的信息层级与克制的光效。设计参考了 [Claude 官方产品页](https://claude.com/product/overview) 的留白与排版，以及 [Qwen 官网](https://qwen.ai/home) 的浅色输入式入口；不使用其品牌素材。

实际业务区以任务列表和操作为主，帮助通过右上角“？”打开。首页新增问题输入与场景示例；点击“开始检查”只把问题带入新建任务弹窗，预览并确认执行后才发送。

## 导航与任务操作

- 正常窗口显示图标和中文导航。778像素宽度仍显示完整文字；手动折叠后使用“图标＋下方名称”，390像素窄屏也保留文字，避免纯图标难以识别。
- 直接打开程序进入“任务”。支持全部、进行中、需处理、已完成分组，搜索与分页查询完整数据库，不限于最近150条快照。
- “新建任务”弹窗复用原有问题、平台、会话和预览功能；关闭弹窗保留本标签页草稿。关键词库“使用”会直接打开填好的弹窗。只有点击创建执行才会提交任务。
- 主内容独立滚动，顶部工具栏、左侧导航和底部状态栏保持固定。状态栏显示真实队列状态与当天额度，不使用假实时数据。
- 表格、表单、弹窗、平台连接向导、计划与统计使用一致的浅色组件；首页保留可拖动网络球、可点击平台节点、暂停和重置操作。网络连线是交互示意，实际连接状态在平台卡片说明。
- 651–1050像素窗口内任务表按比例排版，操作按钮可换行；更窄屏保留表格内部横向滚动，不把整页撑宽。

## 趋势图的含义

- 蓝色实线：已核对回答总数。
- 紫色虚线：其中提及合作品牌的回答数。
- 青色点线：其中提及企业的回答数。

图旁常驻中文图例与单位“条回答”，纵轴给出数量，悬停数据点可查看当日三项数值。品牌与企业分别统计，同一回答可以同时计入两者。统计范围与看板筛选一致，名称出现不等于正向推荐。

## 知乎原会话适配

知乎直答使用独立搜索结果页，不是其他平台的聊天气泡结构。旧规则未识别主问题和回答结束工具栏，因而保留了正文但提示“待核对”。新版要求搜索结果路径、唯一完整原问题、唯一正文和真实结束控件同时成立，并排除侧栏历史条目；稳定且未处于生成状态才自动校验。

本机这条公司询问已从原会话重新采集804字并自动校验，没有重发问题。无法确认对应关系或结束状态的其他记录仍保留“待核对”，不能把其状态直接改成成功。自动校验验证采集完整性，不核实第三方回答的事实或推荐排名。

## 独立窗口

Windows双击`open_client.bat`或`start.bat`，环境准备完成后优先用已安装的Edge应用窗口打开任务页，无地址栏和普通浏览器标签页。该窗口使用独立的本机`runtime/client-shell`资料目录，与六个平台的专用登录资料分开。

`open_browser.bat`或`python start_desktop.py --browser`保留浏览器打开方式。未找到Edge或独立窗口启动失败时会回退浏览器；后台监管和登录自动启动方式保持。

这是基于本机服务和Edge应用窗口的客户端入口，源码包仍需要Python环境和Edge，不是已编译的免安装EXE。启动脚本负责创建虚拟环境与安装依赖；登录自启只启动后台，不自动弹出客户端窗口。

## 防止旧界面继续显示

根页面、静态资源和接口返回`Cache-Control: no-store`。页面记录UI版本，后台bootstrap提供版本；检测到更新时，空闲窗口自动重新加载一次。打开弹窗、存在未保存表单或写入请求进行中时延后，并给出明确更新提示，不覆盖输入、不重放请求。同一标签页一分钟内不连续自动重载，防止部署不完整时刷新循环。

v1.3.x老标签页本身没有升级检测代码，首次更新需重新加载；当前新版之后会自动检测。页面与后台的版本均可通过底部版本和健康检查核对。

## 验证

148项单元/HTTP测试通过，覆盖完整数据库分组、分页、筛选、缓存头、版本、客户端窗口参数与浏览器回退。浏览器检查任务弹窗、草稿保留、关键词使用、只读筛选、分页、9个页面、正常/折叠导航文字、778/390像素布局、统一浅色背景、三条图例、首页问题入口和升级保护。另有7个知乎DOM场景验证：准确对应、排除历史、错误路径、多正文、缺少结束标记、生成中与最终正文提取。

升级测试中，空闲页面自动更新一次；未保存的表单保持输入并延后更新。没有新增批次或向平台发送问题。README中的客户端截图使用示例数据，不包含实际平台会话内容。
