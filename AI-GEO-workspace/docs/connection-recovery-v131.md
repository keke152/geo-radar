# v1.3.1：本地服务断线、重复提示与后台启动

2026-11-04排查时，`127.0.0.1:8020`的本地服务没有运行。浏览器保留着已经打开的页面，每6秒请求一次后台，旧代码在每次失败时都会弹出原始的“Failed to fetch”，因此提示不断出现。旧版本未保留服务退出日志，无法仅凭此现象确定是关机、关闭终端还是进程异常退出。

## 已修复

1. **断线只显示固定提示条**：中文说明本地服务状态、保留上次数据，并提供“立即重连”。原始网络错误不再反复弹窗；主页服务指示和平台状态卡同步显示暂不可用。
2. **后台读取有退避**：失败后依次约6、12、24、48秒重试，最多60秒一次；恢复正常后回到6秒。切回页面或点击重连可立即检查，后台标签不持续发出读取请求。
3. **超时与异常返回有明确提示**：普通读取最多等待12秒；较长的连接、资料上传等操作保留独立超时。HTTP错误、非JSON数据与服务断线分别处理。
4. **任务操作不自动重试**：创建任务、修改配置等失败时保留用户输入。后台恢复只重新读取数据，不重发关键词、不重试写入请求，不把旧任务改成成功。
5. **独立后台启动**：双击新版`start.bat`，安装缺失依赖后由`start_desktop.py`委托Windows桌面启动`pythonw.exe`后台并确认就绪，再打开首页。重复点击会复用已有服务；后台不依赖当前命令执行进程；启动锁防止并发启动，端口被其他程序占用时明确报错。
6. **日志可追查**：后台日志在默认`runtime/logs/server.log`，最多保留3份滚动备份，每份约2MB；启动错误在`runtime/logs/startup.log`。常规HTTP访问日志关闭，避免每6秒刷一行。使用自定义`JUNHE_HOME`时，日志位于对应数据目录的`logs`。

## 使用

解压新版后双击`start.bat`。本机后台独立运行，启动命令窗口可以结束。电脑关机或重启后，仍需再次双击启动；没有设置开机自启动。

浏览器若显示固定的“本地服务未连接”，先启动`start.bat`，再点“立即重连”或等待自动恢复。仅刷新浏览器不能启动一个已经停止的本机服务。使用手动命令`python launcher.py`时仍需要保留该终端。

项目已有资料、连接配置和任务保存在原有`runtime`目录。版本压缩包按原约定只含源码、文档与启动脚本，不含本机登录目录、密钥和任务数据库。更新原项目时请保留该目录与本机`.env`。
