# v1.9.0：深空地球场景与平台选择

此文保留初版地球场景的设计与资源说明。当前版本已更新为 [v1.9.1 地球与六平台卫星轨道](earth-scene-v191.md)。

首页以动态星空和地球夜景构成主要视觉。地球模型呈现大陆与海洋的明暗、大气层边缘和夜景光点，周围轨道与平台节点延续网络探索的交互。内部工作台同步改用深海蓝背景、分层蓝色面板、高对比浅色正文及冰蓝强调色，任务、统计、资料、连接与记录功能保持原有流程。

## 场景与数据的边界

地球、夜景光点、大气层、星空与轨道均为本地渲染的视觉演示，不是实时卫星影像，也不展示真实的全球请求、平台服务器位置或流量。节点之间的连线不代表一次问题已经发送。

平台名称与连接状态来自本机工作台数据。点击某个平台节点，只查看对应连接状态；“设置连接”打开该平台向导。窗口已打开、配置已保存与实际登录有效是不同状态，需要按连接向导完成核对。

球体支持拖动旋转、方向键调整、暂停与重置。减少动画偏好用于限制自动运动，用户仍可主动查看场景和平台状态。

## 从问题到检查

首页保留问题输入和“选择平台并检查”按钮，输入框下不提供示例按钮或辅助说明。简洁三步流程为：写下问题、选择平台、确认后发送。

1. 输入要检查的实际问题，点击“选择平台并检查”。这一步只把问题带入任务弹窗。
2. 在弹窗中选择豆包、DeepSeek、Kimi、千问、腾讯元宝或知乎直答，可以单选或多选。首次打开平台选项默认全选，后续以当前勾选为准；可以取消不需要的平台。
3. 核对问题、会话方式和实际提示词，再点击“创建并执行”。随后在任务与记录页查看进度、回答及来源。未准备好的平台显示待连接或配置。

发送目标始终以任务弹窗中的勾选为准。点击地球上的平台节点、拖动球体、暂停动画、打开连接设置或仅填写问题，都不会创建检查任务。

网页与官方 API 的结果分别记录。独立对话与连续会话分别统计，资料研读和自然发现的口径见 [README 数据与统计边界](../README.md#数据与统计边界)。

## 记录与验证

本次视觉更新保持导出、回收站、每日计划及后台执行逻辑。记录清理仍须预览并确认；恢复记录不会自动重新提问。操作边界见[导出与记录回收站说明](records-export-and-trash.md)。

自动化验证使用临时数据库或隔离的模拟记录；界面截图使用示例数据。任务数量、连接状态及回收站内容随本机实际操作变化，不能从演示场景或截图推断。

## 地理资源

大陆轮廓使用 [Natural Earth 1:110m Land](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/) 的陆地数据，坐标简化后保存在 `static/globe-land.json`；运行时仅从本机读取，不需要地图服务或CDN。Natural Earth 的[使用条款](https://www.naturalearthdata.com/about/terms-of-use/)将其地图数据置于公共领域，项目内同时保留 `static/globe-land-LICENSE.txt` 来源说明。

该地理图层只呈现陆地，不绘制政治边界。海洋色彩、云层、城市光点和星链效果为本地视觉设计，不作为测绘、人口、卫星位置或联网情况的依据。
